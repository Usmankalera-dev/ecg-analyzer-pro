❤️ ECG Analyzer Pro

by Usman Kalera  •  Production build v1.0 — 2 November 2026  •  Browser-only — your ECG photo never leaves your device
RESEARCH AND EDUCATIONAL SCREENING AID — NOT A CERTIFIED MEDICAL DEVICE, NOT A DIAGNOSIS.
This production-quality web app measures what it can see in one ECG strip (heart rate, rhythm, QRS width, ST level). It does not diagnose myocardial infarction, conduction disease, hypertrophy or any other condition. A single lead cannot diagnose heart disease. Clinical production diagnosis would require validated models, multi-lead clinical validation, cardiologist review and regulatory clearance — none of which this tool claims. If you have chest pain, breathlessness or any emergency, call emergency services and see a qualified doctor immediately. Do not use this result to start, stop or change any treatment.

1 — Upload an ECG photo

Use a straight, well-lit photo showing the full ECG. Then drag on the image to select a single-lead strip (for example, one Lead II line). If you do not select a strip, the middle band of the full image will be used.
Tip: a tilted or blurry photo gives a wrong result — check the quality score first, then press Analyze.

What was merged from major repositories?

• PTB-XL benchmarking (helme/ecg_ptbxl_benchmarking) — 21,837 recordings, 10 seconds, 12 leads, 5 superclasses NORM / MI / STTC / CD / HYP; ResNet/Inception performed strongest. In this tool those 5 classes are kept only as reference patterns, not as a fake model.
• Open-ECG-Digitizer (Ahus) — 5-step pipeline: crop → segmentation → layout → grid calibration → 2D-to-1D signal. This tool follows the same 5 steps, with manual cropping.
• ECG-code (U-Net digitization) — remove the grid, keep only the waveform, handle overlapping leads. This tool ignores the pink/red grid by colour.
• Isoline (Talha Salman) — quality gate (retake if blurry), browser-only operation, PDF report. This tool gives quality as a number, not just pass/fail.
• ECG-ML micro model idea — lightweight, runs on a phone, no server upload. This tool runs entirely in the browser; no photo is sent to any server.
• PTB-XL-Image-17K idea — paper speed (25 mm/s) and gain (10 mm/mV) calibration. In this tool the user can set duration and pixels-per-mm.

Honest difference: Isoline claims a trained EfficientNet + CNN-Transformer cross-check. This tool makes a smaller, clearer claim: it has no trained disease classifier, so its numbers are only what can be measured from the image. The next step (if you want it) would be to train a real 1D-ResNet on PTB-XL and convert it to ONNX — a separate, large job that cannot be done on a phone.

Sources: PTB-XL paper, helme/ecg_ptbxl_benchmarking, masoudrahimi39/ECG-code, Open-ECG-Digitizer, PTB-XL-Image-17K. This tool does not copy code from those repositories — it merges their ideas into original browser code.
